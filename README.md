## 📖 نمایی کلی


این سند، بازنویسی و تلفیق منابع آموزشی مختلف در زمینه توسعه اندروید است. هدف آن ارائه یک **مقدمه گام‌به‌گام و ساختارمند** برای برنامه‌نویسی اپلیکیشن‌های اندروید، به‌ویژه برای تبلت‌ها، است.

این سند تعدادی از تحولات کلیدی را پوشش می‌دهد:
* معرفی **Android Studio** به عنوان محیط توسعه اصلی
* استفاده از سیستم ساخت **Gradle**
* معرفی **RxJava** برای مدیریت عملیات ناهمزمان
* ساختاردهی پیشرفته برنامه‌های اندروید (قطعات (fragments)، چرخه عمر، معماری کلاینت/سرور)

این سند به‌ویژه به دلیل ارائه یک **چارچوب کلی برای یک اپلیکیشن اندروید مبتنی بر مدل کلاینت/سرور**، که می‌توان آن را در پروژه‌های متعدد مجدداً استفاده کرد، برجسته است.







---



## 🎯 اهداف آموزشی

* درک اصول اولیه توسعه اندروید

* تسلط بر ناوبری بین ویوها و فرگمنت‌ها

* مدیریت چرخه عمر کامپوننت‌های اندروید

* پیاده‌سازی معماری‌های کلاینت/سرور

* ویرایش داده‌ها از طریق رابط‌های کاربری

* معرفی برنامه‌نویسی ناهمزمان با RxJava
